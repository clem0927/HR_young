# 1. Project Overview (프로젝트 개요)

- 프로젝트 제목:LLM을 활용한 IT HR 웹 솔루션
- 프로젝트 설명:LLM을 활용하여 IT회사의 사내 개발자들을 대상으로하는 지능형 HR 웹 솔루션을 개발
- **주제 선정 배경 및 차별점**:
   - 기존의 HR은 개발자들을 위한 맞춤  기능들이 부족
   - 개발자들의 업무 특성에 맞는 기능들을 LLM을 활용하여 구현

# 5. Key Features (주요 기능)
- **회원가입 및 로그인**:
  - 스프링 시큐리티를 활용한 회원가입 및 로그인

- **시큐리티를 통한 접근 통제**:
  - 직책별 시큐리티의 권한 통해 페이지 접근 통제 및 컨트롤러의 메서드 접근 통제

- **캘린더**:
  - 개인별 일정,프로젝트 현황,휴가 현황을 조회 후 시각화 해줌

- **프로젝트 생성**:
  - 소프트웨어공학적인 개발기법에 의거해 개발자 맞춤의 프로젝트를 생성
  - 프로젝트를 생성,수정,삭제,조회 가능
  - 모든 조회에는 페이징 처리와 검색 기능 구현
  - 프로젝트 참여자 배정

- **프로젝트 관리**:
  - 프로젝트 참여자들이 프로젝트 단계별 목표를 설정하고 그에 맞는 산출물을 업로드
  - 산출물은 다운로드 및 이미지일 경우 미리보기 가능

- **AI 단계 도우미**:
  - 프로젝트 단계 추가시 프로젝트 내용이나 목표를 AI가 직접 생성해줌
  - Ollama로 실행한 로컬 LLM(Gemma3:4b)을 통해 동작

- **AI 챗봇**:
  - CSV파일 기반 RAG 방식으로 작동
  - 많이 한 질문을 3개까지 보여주는 누적질문 기능
  - 비속어를 필터링하는 비속어 필터 기능
